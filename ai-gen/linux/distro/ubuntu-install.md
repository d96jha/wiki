Du kan installera Ubuntu på en Raspberry Pi med hjälp av Raspberry Pi Imager.
[1](https://ubuntu.com/download/raspberry-pi)

## Snabbstartsguide

1. Ladda ner Imager: Installera verktyget på din dator (eller direkt via terminalen på Ubuntu med sudo snap install rpi-imager). [1](https://ubuntu.com/download/raspberry-pi)
2. Välj operativsystem:
	• Öppna programmet och gå till Other general-purpose OS -> Ubuntu.
	• Välj mellan Ubuntu Server (rekommenderas för lägre resursförbrukning) eller Ubuntu Desktop. [1](https://www.reddit.com/r/raspberry_pi/comments/1l2mtnk/are_there_any_drawbacks_to_using_ubuntu_rather/), [2](https://ubuntu.com/tutorials/how-to-install-ubuntu-on-your-raspberry-pi)
3. Välj lagring: Sätt i ditt microSD-kort eller anslut en SSD/NVMe-enhet. [1](https://ubuntu.com/hardware/docs/boards/how-to/ubuntu_supported/raspberry-pi/), [2](https://ubuntu.com/hardware/docs/boards/tutorials/raspberry-pi-other/)
4. Konfigurera: Klicka på inställningsikonen (kugghjulet) innan du flashar för att ställa in Wi-Fi, användarnamn och aktivera SSH om du kör headless (utan skärm). [1](https://forums.raspberrypi.com/viewtopic.php?t=367599), [2](https://ubuntu.com/tutorials/how-to-install-ubuntu-on-your-raspberry-pi)
5. Skriv och starta: Tryck på "Write", vänta tills det är klart, sätt i kortet i din Raspberry Pi och starta upp. [1](https://documentation.ubuntu.com/core/tutorials/try-pre-built-images/use-raspberry-pi-imager/), [2](https://ubuntu.com/download/raspberry-pi)

## Systemkrav & Modeller

* Modeller som stöds: Raspberry Pi 4, Pi 5, Compute Module 4/5, Zero 2 W m.fl. (även äldre Pi 3 för Server). [1](https://ubuntu.com/hardware/docs/boards/how-to/ubuntu_supported/raspberry-pi/)
* Minimikrav för Desktop/Server: Kräver vanligen minst 4 GB RAM för nyare Desktop-versioner (eller 2 GB på äldre versioner) samt minst 16 GB lagring. [1](https://ubuntu.com/download/raspberry-pi), [2](https://ubuntu.com/hardware/docs/boards/how-to/ubuntu_supported/raspberry-pi/)
* Standardinloggning: För förinstallerade avbildningar är standardanvändarnamn och lösenord oftast ubuntu (om du inte angett annat vid konfigurationen). [1](https://ubuntu.com/hardware/docs/boards/how-to/ubuntu_supported/raspberry-pi/)
